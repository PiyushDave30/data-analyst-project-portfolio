## 📋 Dashboard Overview

Dashboard titled **"Zomato Analytics Dashboard"** with bold red theme:

### KPI Banner (Top Row)
| Metric | Value |
|--------|-------|
| Total Restaurants | 9,551 |
| Average Rating | 2.9 |
| Avg Cost for Two | 1,199 |
| Total Votes | 14,98,645 |
| Restaurant with Online Delivery | 25.66% |
| Table Booking % | 12.12% |

### Left Panel — Filters & Parameters
- **Impact on Rating** toggle — Table Booking / Online Delivery
- **No. of Restaurant** toggle — Online Delivery / Table Booking
- **Parameter** — Average Rating / Total Votes / Avg Cost for Two / Total Restaurants
- **City Filter** — full multi-select city list (141 cities)

### Main Visuals
| Visual | Description |
|--------|-------------|
| **Country-wise Total Votes** | Bar chart — India dominates (11,87,163), USA (1,85,848), UAE (29,611) |
| **Country Summary Table** | Country, ID, Avg Cost, Avg Rating, Restaurants, Votes for all 15 countries |
| **Online Delivery Donut** | Yes: 2,451 / No: 7,100 out of 9,551 total |
| **Table Booking Impact on Rating** | Bar — Yes: 3.5 avg rating / No: 2.8 avg rating |
| **Top 10 Cuisines** | Lollipop chart — North Indian (936) leads |
| **Restaurant by Price Range** | Lollipop — Price 1 (4,444), Price 2 (3,113), Price 3 (1,408), Price 4 (586) |
