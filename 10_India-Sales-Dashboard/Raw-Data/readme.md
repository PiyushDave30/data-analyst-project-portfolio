# Raw Data — India Sales Dashboard

This folder contains the raw India sales dataset used for this project.

---

## Files in This Folder

| File Name | Description |
|-----------|-------------|
| `india_sales_data.csv` | Main sales dataset with all transactions |

---

## Dataset Details

| Property | Value |
|----------|-------|
| **Domain** | India Sales — Manager/Region/Category data |
| **Years Covered** | 2021, 2022, 2023, 2024 |
| **Total Sales** | 589.65K |
| **Total Profit** | 129.07K |
| **Total Orders** | ~1,600 |
| **Managers** | 3 (Mahesh, Suresh, Ramesh) |
| **Regions** | 4 (West, North, South, East) |

---

## Key Fields

| Field | Description |
|-------|-------------|
| `Manager` | Sales manager (Mahesh / Suresh / Ramesh) |
| `Team Lead` | Team lead under each manager |
| `Region` | West / North / South / East |
| `State` | Indian state |
| `City` | City name |
| `Category` | Technology / Furniture / Office Supplies |
| `Sub-Category` | Phones, Bookcases, Copiers, Chairs, etc. |
| `Sales` | Transaction sales amount |
| `Profit` | Profit per transaction |
| `Order ID` | Unique order identifier |
| `Year` | 2021 to 2024 |
