# Raw Data — Brew Metric Coffee Shop Analytics

This folder contains the dataset used for the Brew Metric Coffee Shop Analytics project.

---

## Files in This Folder

| File Name | Description |
|-----------|-------------|
| `coffee_shop_sales_data.xlsx` | Main dataset — 5,000 order records |

---

## Dataset Details

| Property | Value |
|----------|-------|
| **Source** | Brew Metric Coffee Shop dataset |
| **Period** | January – May 2024 |
| **Total Records** | 5,000 orders |
| **Branches** | 5 |
| **Products** | 17 |
| **Categories** | 5 (Coffee, Cold Beverages, Snacks, Bakery, Tea) |

---

## Key Fields

| Field | Description |
|-------|-------------|
| `Order_ID` | Unique order identifier |
| `Branch` | Branch name (Banjara Hills, Gachibowli, Jubilee Hills, Hyderabad Central, Kondapur) |
| `Product_Name` | Name of the product ordered |
| `Category` | Product category |
| `Quantity` | Number of items ordered |
| `Unit_Price` | Price per unit |
| `Sales` | Total sales amount |
| `Cost` | Cost of goods |
| `Profit` | Sales minus Cost |
| `Customer_Type` | Walk-in / Online / Delivery |
| `Payment_Mode` | UPI / Cash / Card / Wallet |
| `Order_Date` | Date of order |
| `Day` | Day of week |
| `Month` | Month name |
| `Time_of_Day` | Morning / Afternoon / Evening / Night |
| `Hour` | Hour of order (0–23) |
| `Employee_ID` | Staff handling the order |
