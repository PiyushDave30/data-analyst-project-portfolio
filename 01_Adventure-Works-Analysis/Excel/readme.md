## 📋 Dashboard Overview

The Excel dashboard is titled **"Sales Performance Dashboard"** and includes:

| Visual | Description |
|--------|-------------|
| **Monthly Sales Table** | Pivot table showing sales per month (Jan–Dec) |
| **Total Sales KPI** | $2,93,58,677 |
| **Total Profit KPI** | $1,20,80,884 |
| **Yearwise Sales** | Bar chart — 2010 to 2014 |
| **Monthwise Sales** | Line chart — Jan to Dec trend |
| **Quarterwise Sales** | Pie chart — Q1 to Q4 breakdown |
| **Gender Wise Sales** | Bar chart — Female ($14,813K) vs Male ($14,545K) |
| **Top 3 Region Wise Sales** | Donut — Australia (9,061K), Southwest (5,718K), Northwest (3,650K) |
| **Sales Amount by Production Cost** | Combo chart — Sales bars + Production Cost line |
| **Weekday Sales** | Bar chart — Sunday to Saturday |
| **Top 5 Products by Sales** | Horizontal bar — Mountain-200 series dominates |

---

## 🛠️ Excel Features Used
- **Pivot Tables** — for all aggregations
- **Pivot Charts** — bar, line, pie, donut, combo charts
- **Slicers** — Year (2010–2014) and Region filters
- **KPI Boxes** — formatted text boxes for Total Sales and Profit
- **Dashboard Layout** — all visuals arranged on a single sheet
