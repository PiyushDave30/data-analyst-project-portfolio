## 📋 Dashboard Plan

The Excel dashboard will cover:

| Visual | Description |
|--------|-------------|
| **KPI Cards** | Total Employees, Attrition Count, Active Employees, Attrition Rate % |
| **Dept-wise Attrition** | Bar chart from pivot table |
| **Gender Distribution** | Pie/donut chart |
| **Income Group Analysis** | Stacked bar — Low / Medium / High |
| **Attrition vs Promotion** | Line chart |
| **Job Role Summary Table** | Pivot table with attrition by role |

## 🛠️ Excel Features to Be Used
- Pivot Tables for all aggregations
- Pivot Charts — bar, pie, line
- Slicers — Department, Gender, Income Group
- KPI text boxes
- Single-sheet dashboard layout
